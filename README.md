# NoteDesk

既存のメモアプリを土台に発展させたローカル専用ノートアプリです。ノートブック、タグ、検索、Markdown、チェックリスト、添付、テンプレート、リマインダー、アーカイブ、エクスポート、ブラウザAI、3ペインレイアウトに対応しています。


## 主な機能

- ノート作成、編集、削除
- ノートブック分類、タグ、自動タグ
- ピン留め、お気に入り、検索、タグ絞り込み
- 日付ビュー、リマインダーあり、アーカイブ表示
- Markdown表示、見出し目次、本文内検索
- チェックリスト形式、テンプレート
- 添付画像・ファイル、ノート複製
- Markdown / TXT エクスポート
- Outlook向け `.ics` 予定ファイル出力
- ブラウザAIによるタイトル作成、要約、タグ提案、チェックリスト化、文章整形
- 安全モード: 軽量AIのみ、高性能AIの外部モデル読込なし
- 自動下書き保存、前回開いていたノート復元
- PWAインストール対応
- ワークスペース、ノート一覧、エディタを並べる3ペインレイアウト

## ブラウザAI

- 高性能、自動、軽量のAIモードを選べます。
- 高性能モードは WebLLM/WebGPU を使い、ブラウザ内でローカルLLMを動かします。
- 安全モードONでは、軽量AIに固定され、高性能AIのモデル読込を行いません。
- 通常版Edgeでは、NoteDesk内の軽量ブラウザAIに自動切替して使えます。
- Microsoft公式のPrompt API対応環境では、ブラウザ内の言語モデルへ自動切替します。Edgeの場合はCanary/Dev 138.0.3309.2以降で `edge://flags` の「Prompt API for Phi mini」を有効化すると利用できます。
- ノート内容は外部APIへ送信しません。
- 高性能モードやPrompt API利用時の初回は、ブラウザがAIモデルを準備するため、ダウンロードや数分の待ち時間が発生する場合があります。

## 保存方式

- ログイン機能とクラウド同期は使いません。
- ノートはこのブラウザ内の `localStorage` だけに保存されます。
- ブラウザのサイトデータを削除すると、ローカルノートも削除されることがあります。
